# flora-custom —— 花艺定制下单网站

> 立项日期：2026-02（以首次提交为准）
> 状态：📋 方案梳理阶段（未开始编码）

## 项目一句话

顾客通过企业微信收到卡片链接 → 手机打开网页 → 浏览品牌介绍 → 分步填写定制需求（花种、色系、上传参考图）→ 选择套餐 → 微信支付当场付款 → 获得订单号和排队位置 → 可随时回看订单、接收进度通知。

1. 技术选型定稿（语言/框架，需评估「降低 AI 生成代码幻觉风险」这一硬性要求）
