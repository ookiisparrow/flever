# 02 · 业务流程（已确认版本 v0.3）

> 状态：主体流程已确认，边界情况（退款、改单、超时未付等）待梳理。
> v0.2/v0.3 新增：付款前排队展示、「作品完成」交付体验（详见 docs/06）；付款模式矛盾已消除；排队规则已确认。

## 主流程（顾客视角）

```
企业微信添加商家
      │
      ▼
企微机器人发送卡片式链接
      │
      ▼
手机点击 → 微信内置浏览器打开网页
      │
      ▼
首页：品牌介绍（花艺工作室展示）
      │
      ▼
点击「开始定制」→ 分步表单
      ├─ 第1步：选择花种
      ├─ 第2步：选择色系
      ├─ 第3步：上传参考图（传给商家）
      └─ 第4步：选择套餐（3 档，差异=价格+花材规格）
      │        └─ 此页同时展示实时排队信息：今日剩余名额 / 最早可排日期
      │
      ▼
确认订单 → 微信支付（JSAPI 一键唤起，当场付清全款）
      │
      ▼
付款成功页：订单号 + 排队位置
      │
      ▼
「我的订单」页：凭手机号可随时回看
      │
      ▼
后续进度（订单确认/排队/制作）→ 服务号模板消息推送
      │
      ▼
作品制作完成 → 商家上传成品图 + 抖音链接 → 服务号推送「已完成」
      │
      ▼
顾客打开专属「作品诞生页」（成品大图/信息回显/跳转抖音，详见 docs/06）
```

## 关键业务规则（已确认）

| 事项 | 规则 |
|---|---|
| 定价模式 | 固定套餐价，当场付清，无人工报价环节 |
| 套餐档位 | 3 档（名称与价格待商家提供） |
| 套餐差异 | 本期仅价格差 + 花材规格差 |
| 参考图 | 顾客上传，供商家制作参考 |
| 订单查询 | 凭手机号回看，无需注册账号 |
| 进度通知 | 通过自有服务号模板消息推送 |
| 入口渠道 | 企业微信机器人发送的卡片链接 |
| 排队规则 | 每日限量接单，名额满自动顺延次日（每日上限数字待商家提供） |
| 作品交付 | 完成后上传成品图+抖音链接，服务号推送专属「作品诞生页」 |

## 待梳理的边界情况（下一步讨论清单）

- [ ] 顾客填了一半退出，要不要保存草稿？
- [ ] 下单后未付款，库存/排队名额要不要锁定？锁多久？
- [ ] 顾客付完款想改需求（换花种/换色系），流程怎么走？
- [ ] 退款政策：付款后多久可全额退？制作开始后呢？
- [ ] ~~排队位置怎么算~~ → ✅ 已确认：每日限量、满则顺延（每日上限数字待提供）
- [ ] 参考图规格限制：张数、大小、格式
- [ ] 同一顾客重复下单怎么处理
- [ ] 商家侧怎么看订单：需要一个简单管理后台（本期是否包含？）
- [ ] 敏感信息：手机号收集需符合个人信息保护要求（隐私政策勾选）

## 已消除的方案分歧

- **付款模式**：曾讨论过「定金+尾款」，✅ 最终确认（v0.3）：套餐全款、当场付清，不做定金环节。

- [ ] 色系选项列表（如暖橙、粉紫、白绿、莫兰迪…）
- [ ] 首页品牌介绍文案与图片（logo、作品图）
