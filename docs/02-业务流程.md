# 02 · 业务流程（已确认版本 v0.3）

> 状态：主体流程与边界规则已全部确认；仅剩商家素材待提供。
> v0.2/v0.3 新增：付款前排队展示、「作品完成」交付体验（详见 docs/06）；付款模式矛盾已消除；排队规则已确认。

## 主流程（顾客视角）

```
企业微信添加商家
      │
      ▼
企微机器人发送卡片式链接
      │
      ▼
手机点击 → 微信内置浏览器打开网页
      │
      ▼
首页：品牌介绍（花艺工作室展示）
      │
      ▼
点击「开始定制」→ 分步表单
      ├─ 第1步：选择花种
      ├─ 第2步：选择色系
      ├─ 第3步：上传参考图（传给商家）
      └─ 第4步：选择套餐（3 档，差异=价格+花材规格）
      │        └─ 此页同时展示实时排队信息：今日剩余名额 / 最早可排日期
      │
      ▼
确认订单 → 微信支付（JSAPI 一键唤起，当场付清全款）
      │
      ▼
付款成功页：订单号 + 排队位置
      │
      ▼
「我的订单」页：凭手机号可随时回看
      │
      ▼
后续进度（订单确认/排队/制作）→ 服务号模板消息推送
      │
      ▼
作品制作完成 → 商家上传成品图 + 抖音链接 → 服务号推送「已完成」
      │
      ▼
顾客打开专属「作品诞生页」（成品大图/信息回显/跳转抖音，详见 docs/06）
```

## 关键业务规则（已确认）

| 事项 | 规则 |
|---|---|
| 定价模式 | 固定套餐价，当场付清，无人工报价环节 |
| 套餐档位 | 3 档（名称与价格待商家提供） |
| 套餐差异 | 本期仅价格差 + 花材规格差 |
| 参考图 | 顾客上传，供商家制作参考 |
| 订单查询 | 凭手机号回看，无需注册账号 |
| 进度通知 | 通过自有服务号模板消息推送 |
| 入口渠道 | 企业微信机器人发送的卡片链接 |
| 排队规则 | 每日限量接单（上限为后台可调参数），名额满自动顺延次日 |
| 作品交付 | 完成后上传成品图+抖音链接，服务号推送专属「作品诞生页」 |

## 边界情况处理规则（v0.5 已确认）

| 场景 | 规则 |
|---|---|
| 表单填到一半退出 | ✅ **自动存草稿**（下次打开继续填） |
| 下单后未付款 | ✅ **锁定名额 30 分钟**，超时释放，不占排队位 |
| 付款后改需求（花种/色系/参考图等） | ✅ **未进入制作前可自由改**；进入制作后需人工协商 |
| 退款政策 | ✅ **进入制作前全额退款**（原路退回）；进入制作后转人工协商 |
| 参考图规格 | ✅ **最多 2 张**，单张 ≤10MB，支持 jpg/png/webp |
| 每日接单上限 | ✅ 不定死数字，**后台可调参数**，商家随时改 |

> 衍生细节待开发时定：草稿保存时长（建议 7 天）；30 分钟倒计时在页面上明示顾客。

## 选单逻辑 v2（v0.25 商家确认，替代旧四步表单）

1. **选主花**：只能从本期推荐主花中选 1~3 种；推荐位 5 个 = 3 主位 + 2 副位；推荐会轮换（商家后台配置）
2. **定款式**：混搭 / 纯粹主花（二选一）
3. **定花叶关系**：花是绝对主角 / 花叶平衡 / 叶才是主角（三选一）
4. **配色彩**：主题色必选其一；辅助色选 0~2 个
5. **选档位**：仅两档 ¥1280 / ¥3280，整体体量相近，差异在花材等级
6. **排期展示**：排队用甘特图类图表，让顾客直观知道何时制作、何时交付
