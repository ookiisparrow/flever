# 01 · 立项背景与目标

## 背景

我们是一家提供花艺作品定制的商家，目前获客与沟通渠道为企业微信：

1. 顾客主动添加企业微信
2. 通过企业微信机器人向顾客发送卡片式网页链接
3. 顾客此前只能通过聊天方式沟通需求，缺少自助下单与付款的通道

## 要解决的问题

- 需求收集靠人工一问一答，效率低、易遗漏（花种、色系、参考图等信息散落在聊天记录里）
- 收款靠人工发码，对账麻烦，顾客体验不正式
- 顾客无法直观了解品牌与套餐档位

## 项目目标

搭建一个**手机端优先**的 H5 网站：

1. **品牌展示**：首页介绍花艺工作室，显得正式、可信
2. **自助下单**：分步表单收集定制需求（花种 / 色系 / 上传参考图 / 选套餐）
3. **当场收款**：微信支付（JSAPI 一键唤起），固定套餐价
4. **订单闭环**：付款后展示订单号 + 排队位置；顾客可凭手机号回看「我的订单」
5. **进度通知**：通过自有服务号的模板消息推送订单确认、排队进度、制作进度

## 明确不做的事（本期范围外）

- 不做人工报价系统（采用固定套餐价）
- 不做复杂的会员体系、积分、优惠券
- 套餐差异本期仅体现为价格差与花材规格差，细节暂不展开
- 不做 PC 端专门适配（移动端优先）

## 成功标准

- 顾客从点开链接到完成付款，全程不超过 5 分钟
- 每笔订单自动生成记录，含表单内容、参考图、金额、排队序号
- 商家可在后台看到所有订单及需求详情
